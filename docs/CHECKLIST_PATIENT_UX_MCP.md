# Checklist UX (MCP) — Pacjent

## Ekran glowny pacjenta
1. Widoczne kafelki pomiarow i akcje.
2. Przycisk "Historia" otwiera historie.
3. Przycisk "Agenci" otwiera agentow.
4. Przycisk "Ustawienia" otwiera ustawienia.
5. Ikona wylogowania w pasku tytulu wraca do wyboru roli.

## Historia pomiarow
1. Lista pomiarow laduje sie z danymi (min. 3 pozycje).
2. Po zapisie nowego pomiaru pojawia sie na liscie.
3. Powrot z toolbaru dziala.

## Agenci
1. Sekcja opiekunow i lekarzy pokazuje liczbe.
2. Lista agentow laduje sie (min. 2 opiekunow i 1 lekarz).
3. Dodaj opiekuna/lekarza: zapis dziala i nowy wpis pojawia sie na liscie.
4. Edycja/usuniecie agenta dziala (pierwszy z listy).
5. Kod dostepu pokazuje 6-cyfrowy kod.

## Ustawienia
1. Profil pacjenta pokazuje dane imie/nazwisko oraz telefon/email.
2. Lista chorob i lekow laduje sie (min. po 1 pozycji).
3. Dodanie choroby/leku aktualizuje liste.
4. Dane osobowe zapisują sie (brak crasha).

## Alerty
1. Lista alertow laduje sie z min/max i statusem.
2. Przejscie do konfiguracji dziala.

## Dialogi pomiarow
1. Zapis cukru/insuliny/tetna/cisnienia wymaga wartosci.
2. Po zapisie dialog sie zamyka.
